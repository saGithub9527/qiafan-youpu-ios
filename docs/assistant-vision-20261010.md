# 拍照识别食材（2026-10-10）

扫描发票与拍照识别物品是两个入口：发票页处理二维码和票面采购草稿；食材页的“拍照识别食材”处理用户拍摄的冰箱、购物袋或单个物品照片。

拍照后先征得本次云端处理同意，再调用 `POST /api/v1/me/assistant/vision`。图片不会在客户端长期保存，也不会直接写入库存。服务端返回结构化 `ADD_INGREDIENTS` 草稿后进入现有“核对并添加食材”页面：每行可修改名称、数量、单位、关联目录食材或取消选择；用户点击批量保存后才写库存。无法识别的内容不会被默认补齐。

支持拍照和系统相册单图选择，最大上传体积 8 MiB。语音仍先由系统 Speech 转成可编辑文本；DeepSeek 官方文档目前只证明图片输入，不把原始语音声明为已接入的多模态输入。

本页依赖十语 `app.text` 文案和既有 UIKit/SnapKit 设计，不新增第三方相机或 OCR SDK。测试服真实识别需要安全注入 `DEEPSEEK_API_KEY` 并完成一次定向调用；没有密钥时服务端保持 503，不伪造成功。

语音输入沿用设备侧 Apple Speech；云端语音 SDK 选型与接入前置条件见后端 `docs/voice-input-provider-evaluation-20261011.md`。
