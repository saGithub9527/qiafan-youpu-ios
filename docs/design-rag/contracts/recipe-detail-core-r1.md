## 已有页面与交互

- 390×844 是参考逻辑画布。PNG 为780×1688，PSD为1170×2532；系统栏和安全区按实际窗口处理，不能直接硬编码参考图的屏幕纵坐标。
- 顶部为返回及居中标题。正文包含通用插画、官方菜谱来源、标题、地区/分类、用时/评分、材料、做法入口；个人作者仅属于明确标注的用户作品。
- 原规格正文参考区域为 `[20,104,350,625]`，固定底栏为 `[0,744,390,100]`。收藏按钮参考框 `[20,760,96,48]`，加入计划为 `[128,760,242,48]`，主次宽度不同。固定底栏不随正文滚动，也不遮挡最后内容；独立详情不显示一级 Tab。
- 返回原入口，保留列表滚动、搜索及筛选上下文。收藏按 recipe 身份同步，不按同名菜品联动用户作品。
- 做法首屏为入口；点击在同一详情展开完整步骤并定位，保持底部操作固定。真实正文数量及本地化可变，不能用示例三步限制真实数据。
- 加入计划进入既有日期、餐次、用量确认；确认才保存。详情动作不直接扣库存或记做菜完成。
- `first-release-core-r1.md` 的既有 Release 例外排除公开作品请求与展示；Debug保留研发设计。该例外不批准重排其他区域或恢复延期入口。
- 示例“官方菜谱”仅为内容来源，15分钟、4.8评分、配方及通用插画均不是实际统计、试做或认证结论。
