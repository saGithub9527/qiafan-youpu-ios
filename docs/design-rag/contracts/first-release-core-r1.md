# 免费首发 Release 页面合同 r1

2026-10-26。依据用户在产品经理聊天授权的首发功能取舍及项目 `docs/产品规划与上线/2026-10-26-产品规划与首发优化方案.md`、放行清单 G08。仅适用于本轮免费1.0 Release；原研发设计与 Debug 能力保留。

四个一级 Tab、各页固定区和滚动区、分类/搜索/筛选、卡片方向、核心尺寸及原有手工保存规则不变。首页仍显示原下一餐卡片；Release 不预热助手、不显示悬浮聊天、不嵌入 Widget、不登记/启动/更新实时活动。服务端内容与状态不能借此重排页面。

计划页仍按原导航及月历/餐单/制定计划合同工作；制定计划只提供既有手工选菜入口，不提供 AI 创建/接受。食材添加保留食材库、自定义名称、按菜谱添加，不提供 AI 添加。

备菜页导航仍为返回、居中标题和手动添加。Release 移出扫描商品条码卡片，下面顺序为冰箱已有/待采购、搜索、原单列库存卡片。库存原位编辑、批次选择、数量/位置保存和归档确认保持。

采购页保持商品名称、独立食材映射、数量/单位、实付价格的原手工路径；Release 移出扫描和商品联网重试，恢复旧草稿不自动发查询。已保存的商品名、规格、来源、金额和历史账单不清理，仍可按既有权限手动查看与编辑。未知价格不改为零，不新增采购或重复入库。

历史聊天、个人贡献、权益等数据的合法只读/清理按 G08/G09 另行核验。该合同不把历史读取转成新私人作品功能，也不为被延期流程提供审核后远程开启通道。源码/RAG通过不等于最终Release包、视觉或业务验收通过。

个人页 Release 移出发布作品、补充图片和新 AI 流程，保留本人作品/草稿、贡献的既有历史入口。作品和本机草稿只读查看并可经明确确认删除；贡献可读、撤回，已有本机贡献草稿在离线时也能查看/删除，不新建或重新提交。菜谱详情不请求或显示公开作品，收藏只展示菜谱。

原 AI 菜单在 Release 对应本机历史聊天的静态阅读，采用既有内容页导航和纵向卡片；仅当前账号/家庭/语言范围，显示原文、角色、时间、失败/停止状态、提示、来源标题与已有图片。没有输入框、服务商、重试、动作执行或请求恢复；查看不改偏好、不触发聊天保留期清理，也不调用云服务。
