# 聊天七天计划与提醒 r5 · 2026-10-20 用户明确变更

继承 r4 的聊天布局、逐字渐现、可自由滚动、语音与统一详情导航。

用户明确请求一周饮食计划时，使用既有周计划提案接口，未来七天默认明日起，明确下周则从下周一。三餐默认1份，展示真实日期、餐次、菜谱和份数。库存为偏好，允许补购；本地模式调用真实菜谱规则工具，不调用收费云模型，不能称为Qwen生成的营养处方。显式关闭联网不读取实时业务。含无法结构化核验的人数、过敏、预算等额外要求时先引导设置，不静默忽略。

聊天提供持久提案入口，可预览后一次确认保存。接受使用APPEND，保留原餐次、同菜份数与完成记录；服务端校验范围、版本与不可变参数，幂等返回计划和购物清单真实回执。补购复用单位换算与库存扣除；信息不足标记待确认，不虚构价格或精确热量。成功后显示实际补购清单，不自动下单。

原Getui/APNs锁屏提醒链路继续保留。未配置Getui的构建使用UserNotifications本机兜底，按真实计划、餐次时区与提前时间预排当天至未来7天，每餐合并多道菜，最多32条。不为已完成、跳过、过去节点排期。原生与远端按配置互斥；关闭、登出、家庭或语言切换移除本模块旧通知，计划变化失效重读。无后台循环保活，后台远程修改需服务器推送，本机定时不是APNs已送达证据。
