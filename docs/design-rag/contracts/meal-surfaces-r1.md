# 用餐计划常驻展示 r1

2026-10-24 用户明确纠正：不要把普通推送作为提醒交付；需要灵动岛可见、App首页常驻及手机桌面小组件，两处主界面都要。

App首页新增固定下一餐区域，复用UIKit/SnapKit主题与现有计划路由；分类、筛选和分页联动不变，新区域位于筛选与推荐标题之间，列表自然下移。空计划也显示真实空态与进入计划入口，不编造一餐。已有光球的通用提示不能盖住该区域。

手机桌面使用原生WidgetKit小/中尺寸组件，显示当前账号和家庭范围下一餐时间、菜谱及简短食材库存状态；无计划、已关闭、未登录、更新失败均明确区分。只共享可展示快照，不共享登录令牌、原始账号家庭ID或健康目标。缓存过期不能当作当前资料；退出/切换账号、家庭或语言清理旧范围。

灵动岛与锁屏使用ActivityKit实时活动。XR无灵动岛；iOS16.1以上可显示锁屏实时活动，支持灵动岛机型显示compact/minimal/expanded。单次活动最长8小时，锁屏最长12小时；不能承诺永久挂岛或绕过用户移除。用餐临近/进行中才保持活动，完成、取消、关闭提醒和退出范围后结束。实时活动本身不发送普通通知横幅。

三个界面使用同一真实计划及食材库存投影。未知数量/换算标为待核对，不把无资料当作库存充足。点击路由仅携带计划UUID/日期/餐次，进入App后重新校验当前登录与家庭权限，不凭深链执行写操作。

后台自动启动与更新需单独接通ActivityKit投递，不能用普通通知送达代替。iOS17.2以下远程启动受系统限制，iOS15只支持首页/桌面组件；用户显式关闭实时活动或移除后不自动强行重建。桌面小组件需要用户通过系统添加，App不能强行放上桌面。
