# AI全屏聊天 r1 · 用户明确变更

来源：2026-10-15本任务用户要求“修改问答模型以及相关流程以及SSE流式输出答案”“AI聊天界面扩展到全屏”“思考过程有可视化过程，参考豆包或者DeepSeek”；随后明确“保留本地默认，可切换云端DeepSeek”。没有已有聊天PNG合同；本页据此次明确变更建立，不改原首页/计划合同。

全屏原生UIKit/SnapKit；系统安全区域内固定导航（返回、标题/模式、记忆），消息列表独立滚动，底部输入区跟随键盘。消息横向边距16pt，输入区正文最大132pt；列表使用UITableView复用，生成中尊重用户向上阅读位置。

用户消息右侧，助手正文左侧。每轮助手有可折叠处理详情：按真实事件展示检索知识、选择工具、读取菜谱/计划/库存、生成回答的当前/完成/失败状态，云端若确实返回公开reasoning_content可单独展开。没有伪造百分比、定时假打字或虚构工具调用。来源/确认操作在完成后展示。

本地默认：Qwen仍在手机推理，本机回调逐段追加正文；不经过HTTP/SSE，不展示工具计划JSON。云端切换仍需现有发送同意；通过自有HTTPS认证接口接收真实SSE，供应商密钥不入App。保留图片与语音转文字输入；停止/返回/后台/账号或家庭或语言变化取消旧回合，partial标为停止/失败，不当作完整回答重送。401只在无事件前允许刷新后重试一次，发生正文后不自动重放或重复计费。

SSE新问答合同：POST me/assistant/chat/stream（JSON及multipart），status(stage)、delta(text)、reasoning(text)、done(answer/model/sources/actions/notice)、error(code/message)。必须终止事件；EOF不当成功。旧preview/vision合同保持，云端新增接口未部署前显示明确不可用，不假装实时流。

本轮不新增业务写操作，不改变积分收费开关，不调用付费云端作测试，不发布环境。对本地原生回调、Unicode/SSE分片、取消、错误及阶段状态做定向测试；重任务串行。视觉、真机完整对话、代理缓冲及生产SDK用量验收单独记录。
