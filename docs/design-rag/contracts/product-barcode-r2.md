# 商品包装条码资料回填 r2 · 2026-10-18

用户反馈扫码后未显示商品名称、数量、价格和重量，并明确应联网查询商品资料。本合同承接 product-barcode-r1，只调整扫码资料和采购商品卡片内的信息；保留扫描页、固定导航、内容滚动区、底部保存、页面边距和卡片尺寸规则。

相机与相册继续仅识别食品包装 EAN/UPC，不提供小票二维码、交易条码或 OCR。合格 GTIN 联网请求固定食品资料源，匿名发送条码和语言；照片、App 凭据、用户填写的内容不发送。受限流通码留本机填写。最近结果可以短时缓存，用户明确重试时绕过缓存，继续遵守请求限流。

资料源有名称时回填可编辑名称；有包装标注或明确的克、千克、毫升、升净含量时回填并展示。原始多包装描述可作参考，不擅自相乘。容量与重量分别保留单位，不把毫升换成克。新扫码商品以可修改的 1 包为起始数量，包装净含量与购买数量为独立字段。实际成交价未知时保持待补全，不采用资料源参考价或猜成零元。

采购卡片展示联网查询结果状态、商品资料来源、购买数量、单位、金额及每包装净含量。未收录、查询失败、限流、内部条码和跳过查询分别提示；明确提供联网重试。未收录仍能填写商品名、关联食材和补充规格。重试只补充尚未填写的名称与规格，保留用户已修改的字段，不重建或覆盖草稿。

查询与相册结果继续绑定账号、家庭、语言和本次操作，离页取消；单行查询反馈不重建正在编辑的整张表单。保存沿用既有采购 API 和幂等确认，条码、来源及查询状态仅保存在本机草稿。扫描、查资料和重试不创建采购或库存。
