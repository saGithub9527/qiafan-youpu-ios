# 商品条码与简明采购录入 r4 · 2026-10-19

用户明确要求：首次进入即可扫码；扫描横线为黑色并上下移动；采购录入只保留可独立编辑的名称、购买日期、购买数量和购买价格；底部保存并放入冰箱，相同物品叠加数量。

相机未就绪时保留全画幅识别，预览就绪后转换并校验识别区域，离开与后台停止相机和动画。只解码食材包装 EAN/UPC，不恢复小票二维码/OCR。识别成功立即进入可编辑草稿，联网名称和包装参考在表单内补全；不阻塞页面跳转，不覆盖用户输入。黑色横线在取景框内往返运动。

新采购不再要求公共食材选择：确认名称后由 Java 解析当前个人/家庭范围内的私有商品身份，不自动映射为泛食材。名称、日期、数量与实际付款独立可改。购买价格是本商品本次实付总额，未知可留空；资料源价格即使有40元也不展示、不填入付款，不根据它猜4元。包装规格仍可作为隐藏的已核验库存换算参考，数据源保留必要署名及信息入口。旧账单已有的外币/优惠保留编辑能力，不清理旧草稿。

保存仍冻结原UUID/body，通过既有采购事务同时写账单、独立入库批次及成本来源，成功后打开冰箱。相同范围/身份/单位/规格/位置的库存由后端全量分组后分页，只读合计数量；不同规格不合并，不改写代表批次数量。更多操作先展开真实批次再编辑，不把合计数写回某一批。精确已知包装可显示瓶/袋数，底层成本与库存基准单位不变。每次采购的日期、价格、有效期和回执仍独立保存。

原导航、卡片尺寸、固定保存区及十语继续沿用。仅实现用户此次明确提出的调整；未经验收不清理历史模型或业务数据。
