# AI全屏聊天 r2 · 2026-10-15用户明确变更

继承assistant-chat-r1的全屏、安全区、16pt横向边距、132pt输入正文上限、UIKit/SnapKit、来源和确认边界。

用户新增明确要求：按钮跳转不打断思考；本地和云端均优化耗时及即时文字反馈；气泡按内容宽度适配；实际到达的回答以Unicode文字簇逐字显示；发送后同步显示“正在思考”，文字有扫光，点击立即展开问题类型与处理计划，不等待模型返回。模型公开分析另行展示；不伪造其内部思考。

每个场景复用同一会话实例，关闭聊天、打开来源/记忆/菜谱、切Tab后再打开仍有原任务和结果。明确停止、退出账号、换家庭/语言、销毁场景才取消。后台系统可能挂起App，恢复前台继续；不承诺系统杀进程后的原生计算无损延续。

云端短暂断线通过原POST的X-QF-Stream-Resume/Last-Event-ID恢复同一用户、语言、请求摘要和Idempotency-Key的任务，最多两次；服务器保留有界事件日志，逐事件id去重，不重调模型/重复扣费。明确停止使用DELETE同一路径。业务拒绝、过期、进程重启或超预算不能冒充续接成功。未部署新协议前明确不可用。

动画仅消费已收到的实际文字，来源/权限/业务状态来自真实完整结果；不按计时器编造答案。Reduce Motion直接显示文字、关闭扫光；离开屏幕暂停UI动效但生成继续。视觉及设备性能实测分别记录。
