# 订阅审核访问 r5

承接用户要求：审核账号能查看完整功能，且能查看订阅内容。r4正常密码登录和r3方案展示保持。

- 明确获赠权益的账号显示“已获赠使用权益”，说明没有产生订阅扣费；不标记为Apple已付费。仍显示实际StoreKit价格、周期、条款、恢复和管理入口，不允许重复购买。
- 服务端独立返回complimentaryAccess。按账号记录授予起止、撤销、原因、操作人；不读取审核IP、日期、设备特征决定放行，不提供客户端写入接口。普通账号仍须订阅，审核过程与用户版本一致。
- 客户端只接受已登录接口返回的60秒内存凭证，退出或切换账号立即清空，不允许离线沿用。服务端每次业务请求检查授予；到期/撤销恢复订阅入口。
- Apple购买签名、绑定、acceptedTransaction逐笔回执及finish顺序完全独立，赠送权益不能确认或伪造交易。另一个未订阅账号用于真实沙盒购买流程。
- 注销账号同时清除赠送记录。AI入口继续全部关闭，保留用户既有数据。原页面结构和UIKit/SnapKit不变，文案同步十语。

实现复用原MyBatis、Flyway与StoreKit，没有新增框架。源码或模拟检查不等于真实Apple购买已通过。
