# 采购、库存与成本客户端实现（2026-10-06）

状态：开发及定向验证中，全范围和测试服尚未验收。

## 页面和交互

- 计划概览的支出/成本入口分别到11花销和13实际成本。金额按币种分开，未定价显示待补全。
- 11：本周/本月/自定义，服务器全范围汇总，DGCharts每日支出（退款负值），采购单按页加载，列表下拉刷新。
- 12/14：账单在原页面进入编辑。本地持久草稿直到点击保存，稳定UUID与请求体冻结后重试；服务器回复后更新关联缓存。查看入库明细仅取本账单批次。
- 13/15：按日/月/自定义读取实际消耗和缺口。补录原取得日期、数量、币种及成本，更新原来源而非新增采购支出；再次读取重算后的记录。
- 手动入库：数量、单位、位置、取得日期、价格、到期日；包装净含量可明确留未知，绝不猜克数。使用同一入库请求原子提交来源字段。
- 退款/退货：业务日期、行金额、退货数量，本地草稿且版本/请求ID保护。版本冲突读取新数据后再确认。
- 19：相机QR持续识别、相册选择、手电筒、离页/后台停止；没有商家数据查询配置，不虚构商品明细。未自动导入的小票可进入手动采购。

## 数据与缓存

新接口见后端 `docs/purchase-cost-contract-20261006.md`。语言只由客户端本地选择并通过Accept-Language传入；请求冻结也保存原语言。个人/家庭及账号草稿隔离，编辑、选单位/日期不发写请求。

保存采购、退款、补价、实际做菜后精确失效采购/支出/消耗/关联库存缓存，不清空全APP。列表读取使用既有请求合并及取消机制；耗时提交使用延迟HUD，不持续展示左上角处理标记。
