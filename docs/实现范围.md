# 当前实现范围

更新：2026-09-11。Swift + SwiftUI、iOS 15 起、SPM；本次在已确认 UI 上接入登录和启动配置。

## 本次已实现

- 启动配置、协议正文和快速 / Apple 登录开关；失败有重试。
- 快速登录一次请求；Keychain 保存设备凭证，重复登录由服务端返回同一账号。
- 每个请求携带 Keychain 保存的 `Device-Id` UUID，秘密凭证独立存储和校验。
- 原生 Apple 授权与后端验证；登录返回系统账号、绑定账号和基本用户资料。
- 会话持久化、启动恢复、集中刷新、退出；退出保留设备凭证。
- 登录勾选默认 false，选择双向缓存；实际协议正文变化后重新选择，未勾选时使用既有安全通知门禁。
- “我的”展示真实基本资料；尚未接入的作品、收藏等统计用占位，不以样例冒充账号数据。
- Debug 请求日志分页列表与详情；按用户最新要求展示原始字段值（含 Token），并限制条数、单条长度和磁盘预算。
- PLCrashReporter 本地崩溃采集、下次启动转存、原始及可读报告、UUID 元数据和有限保留。

## 保留的页面范围

五页欢迎和四个一级 Tab 保留。菜谱、计划、食材继续使用本地样例；二级搜索、详情、计划、备菜、扫码、贡献、作品、偏好等业务尚未接入。欢迎规则仍为 Debug 每次展示，Release 完成后不重复。

后端本次补齐配置与登录、刷新、退出、读取本人资料；没有增加新产品接口。账号一次绑定、设置密码等已有契约仍待对应页面阶段实现。管理后台目前没有协议编辑、用户管理或真实管理员登录能力，服务端协议先通过受控文件配置。

## 环境与验收边界

Debug 指向国内公网测试域名；Release 地址为空，正式环境尚未开放。测试协议标注内部开发测试用途，正式正文、生产地址及发布签名需要上线前配置和验收。AWS 未在本轮部署此登录版本。

Device-Id 不是硬件号，不是密码；不能承诺卸载后 Keychain 一定保留。恢复身份以保存的设备秘密凭证或 Apple 授权为依据。本地协议选择记录与服务端同意快照各司其职，不提交额外版本参数。

真实 Apple 设备授权、iOS 15 真机、硬件 Data Protection 尚需单独验收。崩溃 SDK 不保证捕获系统强杀、所有 OOM 或 watchdog。具体通过项及产物见[验证记录](验证记录.md)。
