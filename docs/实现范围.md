## 本次已实现

- 启动配置、协议正文和快速 / Apple 登录开关；失败有重试。
- 快速登录一次请求；Keychain 保存设备凭证，重复登录由服务端返回同一账号。
- 每个请求携带 Keychain 保存的 `Device-Id` UUID，秘密凭证独立存储和校验。
- 原生 Apple 授权与后端验证；登录返回系统账号、绑定账号和基本用户资料。
- 会话持久化、启动恢复、集中刷新、退出；退出保留设备凭证。
- 登录勾选默认 false，选择双向缓存；实际协议正文变化后重新选择，未勾选时使用既有安全通知门禁。
- “我的”展示真实基本资料和 `/me/content-summary` 统计；作品、收藏、贡献、做菜记录与采购记录页面读取对应服务端数据，不以样例冒充账号数据。
- Debug 请求日志分页列表与详情；按用户最新要求展示原始字段值（含 Token），并限制条数、单条长度和磁盘预算。
- PLCrashReporter 本地崩溃采集、下次启动转存、原始及可读报告、UUID 元数据和有限保留。
- 设置首页及经典橙、自然绿、深色主题选择；主题作用于四个一级页面和通用控件，只保存在本机，切换时不请求接口。
- 登录用户通过 `GET/PUT /me/settings` 同步两类通知偏好；界面语言与主题均由当前客户端本地保存，语言切换不调用设置接口，服务端只按请求的 `Accept-Language` 返回对应内容。
- 编辑资料页支持昵称、国家代码、地区和个人简介，通过 `PATCH /me` 保存并立即更新本机会话资料。
- 账号与隐私页展示用户编号、自定义账号、密码和 Apple 身份状态；自定义账号绑定与改密已有服务端契约，Apple 绑定的客户端入口和后端代码于 2026-10-09 本地构建/定向测试通过，但尚未部署测试服并完成真实 Apple 授权验证。自助注销仍未开放，不能以停用账号冒充清理完成。
- 帮助与反馈页可直接查看常见问题；登录用户可选择分类并通过 `POST /me/feedback` 提交 10–1000 字反馈，失败时保留正文。
- “我的”和设置页均可进入界面语言页面；支持 `zh-Hans`、`zh-Hant`、`en`、`ja`、`ko`、`ru`、`es`、`fr`、`de`、`pt-BR`，选择结果按当前设备保存。
- 菜谱首页、搜索、筛选和详情使用真实服务端数据；支持地区推荐、下拉刷新、上拉自动分页、真实收藏／评分、公开媒体与相关作品，见 [首页实现记录](home-01-ios.md)。
- 个人／家庭计划作用域、计划日历、当日餐次、手动计划、餐次原子替换/清空、备菜汇总、采购单生成/编辑/确认/删除、库存查询/新增/调整/流水、做菜打卡、库存扣减任务状态/重试/取消、个人提醒、家庭与成员管理，以及 AI 周计划提案已接真实接口。计划提醒点击会读取 `plannedMealId` 并定位到对应范围和日期；采购单列表响应已含完整明细，因此单条采购单 GET 保留为可复用 API 封装，不把重复请求当作接入完成条件。逐项状态见[计划客户端接口接入记录](meal-planning-client-integration-20260928.md)。
- 个推官方 iOS SDK 薄适配已接入：隐私同意和计划提醒开启后初始化，CID 通过现有设备接口登记；语言变化更新登记，关闭提醒和退出登录停用设备。测试服个推配置已启用、通知 worker 保持关闭；尚无定向真机送达/点击证据，见[个推接入记录](getui-ios-integration-20260928.md)。
- 小票相机/相册输入、结构化二维码与印字 OCR、用户核对后生成采购草稿已有源码和 29 项模拟器定向检查；缺少真实商家小票与真机相机样本，不能宣称任何商家都可自动提取明细。
- 会员订阅按 2026-10-09 决定先建立默认关闭的只读状态框架；客户端已接状态页，权益、价格、StoreKit 商品和验签尚未定义，当前仍不可购买。
- 设置页清缓存仅清理可重新下载的图片和 URL 缓存；退出登录复用正式会话接口并显示 Loading。
- 用户协议、隐私政策、图片使用授权和图片侵权保护入口优先打开启动配置提供的 HTTPS H5。

## 保留的页面范围

五页欢迎、四个一级 Tab 及设置下的主题、语言、编辑资料、账号与隐私、帮助与反馈页面保留。菜谱、个人计划和食材库存主链路已接服务端；欢迎规则仍为 Debug 每次展示，Release 完成后不重复。

计划和食材主链路已经连接测试服，并做过定向真机检查；这不等于所有页面、设备和外部服务都完成验收。个推/APNs 还缺定向真机送达，DeepSeek 尚无 API Key 和真实推理，菜谱与食材多语言数据缺人工审校覆盖；小票识别缺真实商家样本。会员订阅只交付关闭状态框架，权益与价格以后确定。

设置页服务端范围包括通知设置读写、本人资料更新、反馈提交和协议 H5 地址；主题与界面语言切换不依赖服务端。账号一次绑定和设置密码已有代码，Apple 绑定及注销的实际部署/真机状态以收尾清单为准。用户管理后台与管理员登录属于独立部署入口，不复用客户端页面。

## 环境与验收边界

Debug 指向国内公网测试域名；Release 地址为空，正式环境尚未开放。隐私政策本地 H5 和 App 内置十语副本已升级为 1.4-2026-09-28；公网 H5、服务端登录协议 TXT、生产地址、法律审阅及发布签名仍需上线前部署和验收。AWS 未在本轮部署此登录版本。

Device-Id 不是硬件号，不是密码；不能承诺卸载后 Keychain 一定保留。恢复身份以保存的设备秘密凭证或 Apple 授权为依据。本地协议选择记录与服务端同意快照各司其职，不提交额外版本参数。

真实 Apple 设备授权、iOS 15 真机、硬件 Data Protection 尚需单独验收。崩溃 SDK 不保证捕获系统强杀、所有 OOM 或 watchdog。具体通过项及产物见[验证记录](验证记录.md)。
