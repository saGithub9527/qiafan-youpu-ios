菜谱评分和收藏数、计划金额、食材数量和日期、Debug 个人资料等均是界面样例，不来自真实账号或业务数据。计划页以设备当前日期展示样例餐次，选择其他日期显示空状态；这不是实际计划记录。

## 启动与本地状态

`QFLaunchPolicy` 的规则为 `isDebug || !completed`。Debug 每次显示欢迎；Release 在用户尚未完成引导时显示，完成后直接显示四个主页面。引导仅在安全通知勾选并点击“同意并继续”后完成；“跳过介绍”也需要经过该通知。

当前只保存两类 UI 状态：

- `qfyp.onboarding.completed`：本地欢迎引导完成标记，由根容器写入。
- `qfyp.login.consent`：协议勾选选择，包含 schema、更新时间、UI 文档修订和 `uiOnly` 标记。勾选与取消都写入，损坏或修订不匹配时回到未勾选。

欢迎通知的暂选状态与登录选择独立。登录时若未勾选，所选登录方式只暂存在内存；点击“同意并继续”后消费一次并显示“登录暂未开放”，不会发请求。取消、关闭或重启不恢复待登录动作。

`-QFResetUIState`、`-QFSkipWelcome`、`-QFStartTab`、`-QFPreviewSignedIn` 均由 `#if DEBUG` 限定，详细用法见项目 README。预览登录态不会创建真实身份。

## 未来接入

1. 先确认对应业务页面和字段，再加入网络、模型、Repository 与会话层；当前不创建空接口、请求占位或硬编码服务地址。
2. 接入登录前，提供正式协议正文和版本，更新本地 UI 修订并重新要求选择；现有 UI 勾选不升级为正式协议签署或身份凭证。
3. 快速登录和 Apple 登录需要各自的真实授权及服务端校验。Token 保存、刷新、退出与用户数据隔离在接入阶段实现。
4. 用真实数据替换展示样例时，同时接入加载、空态、错误、分页及权限状态；当前本地筛选和排序不代表服务端规则。
5. 管理后台目前只包含 Vue 品牌空白壳，未建立后台登录、业务菜单、统计或请求。各后台页面在明确功能和权限后独立推进。
