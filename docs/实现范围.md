# 当前客户端实现范围

2026-09-11 最新决定：统一采用 Swift + UIKit + SnapKit，SPM 管理 Alamofire、Kingfisher、SnapKit 和 PLCrashReporter。欢迎、登录、四个 Tab 和 Debug 日志迁移为原生 UIKit；业务接口、账号规则不变。窗口适配与依赖说明见[框架记录](第三方框架与布局适配.md)。以下已接入业务范围继续有效，历史 SwiftUI 布局描述不再代表当前实现。


更新：2026-09-11。Swift + UIKit + SnapKit、iOS 15 起、SPM；本次继续实现已确认的设置与主题页面。

## 本次已实现

- 启动配置、协议正文和快速 / Apple 登录开关；失败有重试。
- 快速登录一次请求；Keychain 保存设备凭证，重复登录由服务端返回同一账号。
- 每个请求携带 Keychain 保存的 `Device-Id` UUID，秘密凭证独立存储和校验。
- 原生 Apple 授权与后端验证；登录返回系统账号、绑定账号和基本用户资料。
- 会话持久化、启动恢复、集中刷新、退出；退出保留设备凭证。
- 登录勾选默认 false，选择双向缓存；实际协议正文变化后重新选择，未勾选时使用既有安全通知门禁。
- “我的”展示真实基本资料；尚未接入的作品、收藏等统计用占位，不以样例冒充账号数据。
- Debug 请求日志分页列表与详情；按用户最新要求展示原始字段值（含 Token），并限制条数、单条长度和磁盘预算。
- PLCrashReporter 本地崩溃采集、下次启动转存、原始及可读报告、UUID 元数据和有限保留。
- 设置首页及经典橙、自然绿、深色主题选择；主题作用于四个一级页面和通用控件并保存在本机。
- 登录用户通过 `GET/PUT /me/settings` 同步主题、界面语言和两类通知偏好；未登录时本机可用。
- 设置页清缓存仅清理可重新下载的图片和 URL 缓存；退出登录复用正式会话接口并显示 Loading。
- 用户协议、隐私政策、图片使用授权和图片侵权保护入口优先打开启动配置提供的 HTTPS H5。

## 保留的页面范围

五页欢迎、四个一级 Tab、设置和主题页面保留。菜谱、计划、食材继续使用本地样例；二级搜索、详情、计划、备菜、扫码、贡献、作品、偏好、编辑资料、账号与隐私和帮助反馈等业务尚未接入。欢迎规则仍为 Debug 每次展示，Release 完成后不重复。

设置页新增的服务端范围只包括本人设置读写和协议 H5 地址；账号一次绑定、设置密码等已有契约仍待对应页面阶段实现。用户管理后台与管理员登录属于独立部署入口，不复用客户端页面。

## 环境与验收边界

Debug 指向国内公网测试域名；Release 地址为空，正式环境尚未开放。测试协议标注内部开发测试用途，正式正文、生产地址及发布签名需要上线前配置和验收。AWS 未在本轮部署此登录版本。

Device-Id 不是硬件号，不是密码；不能承诺卸载后 Keychain 一定保留。恢复身份以保存的设备秘密凭证或 Apple 授权为依据。本地协议选择记录与服务端同意快照各司其职，不提交额外版本参数。

真实 Apple 设备授权、iOS 15 真机、硬件 Data Protection 尚需单独验收。崩溃 SDK 不保证捕获系统强杀、所有 OOM 或 watchdog。具体通过项及产物见[验证记录](验证记录.md)。
